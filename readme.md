# Robustness Analysis of Wavelet Packet Synchronous Compression Transformation [with MATLAB Code]

The identification and extraction of the underlying class wave components in complex physical phenomena are of significant importance in modern data science. To reduce the impact of filtering biases, it is challenging to estimate all class wave components simultaneously from their superposition, which is crucial for many scientific problems. The newly developed synchronous compression transform has been proven to be a good choice for simultaneous analysis. Although its mathematical background is clear and has been well developed in noiseless models, there is relatively less research on its robustness under noise.
This paper studies several fundamental robustness aspects of the synchronous compression transform. It demonstrates that vibration component analysis using compactly supported synchronous compression transforms is feasible, and conditions for precise and robust estimation are given. Considering generalized Gaussian random noise, we address the existing issues of multi-scale robustness of existing synchronous compression transforms in both one-dimensional and two-dimensional domains. The results indicate that their multi-scale robustness can be improved by adjusting the corresponding multi-scale geometrical properties in the frequency domain. This dependence clarifies quantitative probability analysis. As an addition, new insights and numerical implementations are introduced to achieve better accuracy and robustness. A software package accompanied by several examples of severe noise is used to demonstrate these attributes.
